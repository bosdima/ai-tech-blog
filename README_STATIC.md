# AI Tech Blog - Автоматическая система обновления

## 🎯 Цель
Создать гибридную систему, где:
- **Статическая версия** работает 24/7 на Vercel (не зависит от ПК)
- **Hermes** используется только для обновления контента

## 🚀 Как использовать систему

### 1. Для ручного обновления контента:
```bash
# Запускаем полную систему обновления
node update-manager.js manualUpdate
```

### 2. Для генерации только статической версии:
```bash
# Генерируем статическую версию
node update-manager.js generateStatic
```

### 3. Автоматическое обновление через Hermes:
```bash
# Скрипт для автоматического обновления (когда Hermes запущен)
./update-static-site.sh  # Linux/Mac
update-static-site.bat   # Windows
```

## 📁 Структура файлов

- `index-static.html` - основная статическая страница
- `vercel.json` - конфигурация для Vercel (статическая версия)
- `vercel-dynamic.json` - конфигурация для динамической версии
- `update-manager.js` - главный скрипт управления
- `update-static-site.sh/bat` - скрипты для автоматического обновления

## 🔧 Принцип работы

1. **Когда ПК выключен**: Сайт работает на статической версии на Vercel
2. **Когда Hermes запущен**: 
   - Запускается обновление контента
   - Генерируется новая статическая версия
   - Автоматически разворачивается на Vercel
