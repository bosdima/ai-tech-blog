# AI Tech Blog - GitHub Pages

🤖 Автоматический блог о технологиях и искусственном интеллекте

## 📝 О проекте

Этот блог автоматически генерирует статьи о технологиях, ИИ, криптовалютах и других актуальных темах. Обновление происходит каждые 2 часа через GitHub Actions.

## 🚀 Функции

- ✅ Автоматическое генерирование контента
- ✅ Монетизация через AdSense и партнерские программы
- ✅ Криптовалютная тематика
- ✅ Обновление каждые 2 часа через GitHub Actions
- ✅ Полностью бесплатно на GitHub Pages
- ✅ Доступно из России без VPN

## 🚀 Как запустить на GitHub Pages:

1. **Создайте репозиторий** на GitHub
2. **Загрузите файлы** этого проекта
3. **Настройте GitHub Actions** для автоматического обновления
4. **Включите GitHub Pages** в настройках репозитория
