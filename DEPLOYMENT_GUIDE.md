## 🚀 Развертывание на Vercel (пошагово):

### 1. **Зарегистрируйтесь на Vercel:**
- Перейдите: https://vercel.com
- Зарегистрируйтесь через GitHub

### 2. **Создайте проект:**
- Нажмите "New Project"
- Выберите этот репозиторий
- Настройте:
  - Framework: **Other**
  - Build Command: `npm install`
  - Output Directory: `.`
  - Install Command: `npm install`

### 3. **Настройте окружение:**
- Добавьте переменные окружения (если нужно)
- Нажмите "Deploy"

### 4. **Активируйте сайт:**
- После развертывания сайт будет доступен по Vercel URL
- Привяжите домен (опционально)
